# "메일로 받아보기" 발송 서버 배포 (Google Apps Script)

GitHub Pages는 정적 사이트라 메일을 보낼 수 없어서, 회사 구글 계정의 Apps Script 웹 앱을 발송 서버로 씁니다.
별도 서버나 비용이 들지 않습니다. (Workspace 계정 기준으로 하루 약 1,500통까지 보낼 수 있습니다.)

## 배포 (5분)

1. https://script.google.com 에서 **새 프로젝트**를 만들고 이름을 `Relog`로 정합니다.
2. `Code.gs` 내용을 이 폴더의 [Code.gs](Code.gs)로 바꾸고 저장합니다.
3. 함수 목록에서 `testSendToMe`를 골라 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   본인 메일로 데모 리포트가 오면 정상입니다.
4. 오른쪽 위 **배포 → 새 배포**에서 유형을 **웹 앱**으로 고르고 아래처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 발급된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을
   [docs/assets/relog.js](../docs/assets/relog.js)의 `MAIL_ENDPOINT`에 넣고 push합니다.

### 액세스 권한에 따른 동작

| 웹 앱 액세스 | 페이지에서의 동작 |
|---|---|
| **모든 사용자** | 대화상자 안에서 바로 발송하고 결과를 표시 |
| **vntgcorp.com 내 모든 사용자** (회사 정책상 '모든 사용자'를 고를 수 없는 경우) | [보내기]를 누르면 새 탭이 열리고, 회사 구글 로그인 상태로 발송한 뒤 그 탭에 결과를 표시. 로그인하지 않은 외부인은 보낼 수 없음 |

페이지는 처음 열릴 때 발송 없이 확인용 요청(`probe`)을 한 번 보내서 어느 방식을 쓸지 정합니다.

`Code.gs`를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

## 남용 방지

공개 페이지에 붙는 발송기이므로 다음 장치를 둡니다.

| 장치 | 내용 |
|---|---|
| 수신 도메인 제한 | `ALLOWED_DOMAINS`(@vntgcorp.com)로만 발송. 외부 주소를 대상으로 한 스팸 발송에 악용할 수 없음 |
| 발송량 제한 | 주소별 6시간에 3통, 전체 6시간에 100통 |
| 허니팟 | 숨은 입력칸을 채운 봇 요청은 조용히 무시 |
| 고정된 본문 출처 | 요청자는 `source`(demo/live/live-monthly)와 `kind`(windows/linux)만 고를 수 있음. 본문과 첨부는 `PAGES_BASE` 아래 manifest에 있는 파일만 사용 |
| 개인정보 | 발송량을 셀 때 이메일 원문 대신 SHA-256 해시를 쓰고, 6시간 뒤 자동 삭제 |
